## 🏛️ Typografische Gliederung & Epochen | Typographic Categories Explained

### 1. 📜 Historische Normalfraktur & Barock-Fraktur (`01_Historical_Fraktur_Normal`)
- **Beschreibung**: Die quintessenzielle Schrift des deutschen Buchdrucks vom 16. Jahrhundert bis 1941.
- **Enthaltene Klassiker**: Theuerdank-Fraktur, Unger-Fraktur, Zentenar-Fraktur, Barock-Fraktur, Breitkopf-Fraktur, Potsdam, Tannenberg, Mainzer Fraktur, Offenbacher Fraktur, Kanzleischriften.

### 2. 🪶 Schwabacher, Textura & Rundgotisch (`02_Historical_Schwabacher_Textur`)
- **Beschreibung**: Die Schriften der Gutenberg-Bibel und der Reformation Martin Luthers.
- **Enthaltene Klassiker**: Gutenberg Textura, Alte Schwabacher, Wallau Rundgotisch (Rudolf Koch), Hans Sachs Gotisch, Rotunda, Fette Schwabacher.

### 3. ✍️ Deutsche Schreibschriften (`03_Cursive_Kurrent_Suetterlin`)
- **Beschreibung**: Die traditionsreichen Handschriften des deutschsprachigen Raums.
- **Enthaltene Klassiker**: Sütterlinschrift (1911 von Ludwig Sütterlin für preußische Schulen entworfen), Kurrentschrift des 18. und 19. Jahrhunderts, Offenbacher Schrift, Deutsche Normalschrift, Schul- und Fibelschriften (Fibel Nord/Süd).

### 4. ⚔️ Moderne Gotisch & Zeitgenössische Blackletter (`04_Modern_Gothic_Medieval_Blackletter`)
- **Beschreibung**: Zeitgenössische Interpretationen, Heavy Display Blackletter und mittelalterliche Prachtschriften.
- **Enthaltene Klassiker**: Fette Fraktur, Grenze Gotisch, Stella Mystica, Germania One, MedievalSharp, Pirata One, Blackletter Display, Gothic Woodtype.

### 5. 🚦 DIN 1451 & Deutsche Industrie-Normung (`05_Iconic_DIN_Industrial_Engineering`)
- **Beschreibung**: Die wohl einflussreichste technische Normschrift der Welt (seit 1931).
- **Enthaltene Klassiker**: DIN 1451 Mittelschrift, DIN 1451 Engschrift, DIN 1451 Breitschrift, Microsoft Bahnschrift (OpenType Variable), Autobahn-Beschilderungsschriften, historische Berliner Email-Straßenschilder.

### 6. 📐 Bauhaus Weimar, Futura & Geometrische Moderne (`06_Bauhaus_Geometric_Futura_ArtDeco`)
- **Beschreibung**: Die gestalterische Revolution des 20. Jahrhunderts aus Weimar und Dessau.
- **Enthaltene Klassiker**: Bauhaus 93, Universal-Alphabet (Herbert Bayer), Paul Renners legendäre **Futura (1927)**, Jakob Erbars Erbar-Grotesk, Rudolf Kochs Kabel, deutsches Art Déco und Jugendstil (Georg Barlösius, Peter Behrens, Lucian Bernhard).

### 7. 🏢 Deutsche Grotesk-Tradition (`07_German_Grotesk_Berthold_Spiekermann`)
- **Beschreibung**: Die Berliner Schule der Sachlichkeit und weltberühmte serifenlose Meisterwerke.
- **Enthaltene Klassiker**: H. Berthold AG (Akzidenz-Grotesk von 1896, der Urahn von Helvetica), Erik Spiekermanns **Fira Sans** (komplette 18-Gewichte-Familie), Fira Mono, Neuzeit Grotesk, Carrois Apostrophe Werkstattschriften.

### 8. 🖋️ Klassische Antiqua & Schriftmeister (`08_Classic_Serif_Zapf_Tschichold`)
- **Beschreibung**: Meisterwerke der deutschen Buchkunst und Schriftgießereien (D. Stempel AG, Klingspor, Haas).
- **Enthaltene Klassiker**: Hermann Zapfs Meisterwerke (**Palatino**, **Optima**, Aldus, Melior, Zapfino), Jan Tschicholds **Sabon**, Justus Erich Walbaum (Walbaum-Antiqua 1800).

### 9–13. 🌐 Moderne Schriften mit vollständigen Umlauten (`09_..._A-C` bis `13_..._S-Z`)
- **Beschreibung**: Tausende moderne, geprüfte Schriftarten in allen Stilen (Sans-Serif, Serif, Display, Slab, Monospace), die garantiert alle deutschen Umlaute (`Ä, ä, Ö, ö, Ü, ü`) sowie das kleine und große Eszett (`ß, ẞ`) unterstützen.
- **Unterteilung**: Alphabetisch balanciert (A–C, D–G, H–L, M–R, S–Z), sodass jeder Ordner garantiert **unter 800 Dateien** bleibt – für reibungsloses Browsen auf GitHub und fehlerfreien Download.

## 🇩🇪 Deutsche Sonderzeichen & Tastatur-Kürzel | German Character Reference

Jede Schriftart in diesem Archiv wurde auf korrekte Darstellung der deutschen diakritischen Zeichen überprüft:

| Zeichen | Bezeichnung | Unicode | HTML Entity | Windows Alt-Code | Mac Tastaturkürzel |

| **Ä** | A mit Umlaut (groß) | `U+00C4` | `&Auml;` | `Alt + 0196` | `Option + u`, dann `A` |
| **ö** | o mit Umlaut (klein) | `U+00F6` | `&ouml;` | `Alt + 0246` | `Option + u`, dann `o` |
| **Ö** | O mit Umlaut (groß) | `U+00D6` | `&Ouml;` | `Alt + 0214` | `Option + u`, dann `O` |
| **ü** | u mit Umlaut (klein) | `U+00FC` | `&uuml;` | `Alt + 0252` | `Option + u`, dann `u` |
| **Ü** | U mit Umlaut (groß) | `U+00DC` | `&Uuml;` | `Alt + 0220` | `Option + u`, dann `U` |

## 💻 Installationsanleitung | Installation Guide

### 🪟 Windows (10 / 11)
1. Laden Sie den gewünschten Ordner oder das Gesamtarchiv herunter und entpacken Sie die `.zip`-Datei.
2. Markieren Sie die Schriftarten (`.ttf` oder `.otf`).
3. Rechtsklick ➔ **Für alle Benutzer installieren** (oder Doppelklick ➔ *Installieren*).

### 🍎 macOS
1. Öffnen Sie die App **Schriftsammlung** (*Font Book*).
2. Ziehen Sie die Schriftdateien einfach per Drag & Drop in das Fenster oder wählen Sie *Ablage ➔ Schriften hinzufügen*.

### 🐧 Linux (Ubuntu, Debian, Fedora, Arch)
```bash
# Lokales Schriftarten-Verzeichnis erstellen
mkdir -p ~/.local/share/fonts/German_Fonts

# Schriften in das Verzeichnis kopieren und Cache aktualisieren
cp /pfad/zu/den/schriften/*.ttf ~/.local/share/fonts/German_Fonts/
fc-cache -f -v
```

### 🌐 Webdesign & CSS Integration (`@font-face`)
```css
@font-face {
  font-family: 'FrakturKlassik';
  src: url('fonts/01_Historical_Fraktur_Normal/MainzerFraktur.ttf') format('truetype');
  font-display: swap;
}

body {
  font-family: 'FrakturKlassik', Georgia, serif;
}
```
